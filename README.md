# Nami Sushi Bar: tienda en línea de demostración

Página de pedidos para un **restaurante de sushi ficticio**, hecha como proyecto de portafolio por **Jeison Serrano**.

**Nami Sushi Bar no existe.** Los platos, los precios y las sedes son inventados, y el pago en línea no está conectado.

## Qué tiene
- Carta con fotos, categorías, buscador y una ventana por plato con sus opciones (tamaño, salsas extra, bebidas…).
- Carrito de compras que se guarda en el navegador y pide la autorización de datos (Ley 1581 de Colombia).
- **3 idiomas**: español, inglés y japonés. Toda la página cambia, incluida la carta.
- **3 monedas**: pesos, dólares y yenes, con la tasa de cambio actualizada desde internet.
- Animaciones: partículas al cerrar ventanas, foto de portada con movimiento, carrusel de favoritos y barra que palpita.
- Páginas de inicio, menú, cada plato, sedes, nosotros, contacto (por WhatsApp), franquicias, puntos y políticas.
- Modo oscuro, y diseño para celular, tablet y computador.

## Tecnología
HTML, CSS y JavaScript puro, sin frameworks ni servidor. Para verla, abre `index.html` en el navegador.
